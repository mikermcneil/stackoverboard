> **Here for the MCP server?**  That's what this game was built to showcase!  Check out `api/hooks/mcp.js` to see a single file you can drop into your Sails app to automatically expose it as a configurable MCP server, for use from Slack, Teams, Claude, Codex, etc.  In the example of this game, there is a shared world and species index (procedurally generated by each player, but saved via the Sails backend, similar to [Spore](https://en.wikipedia.org/wiki/Spore_(2008_video_game)) or [No Man's Sky](https://en.wikipedia.org/wiki/No_Man%27s_Sky)).
>
> For the app in this repo, that means asking questions about the shared world or history.  But for your Sails app, that's anything you can imagine.  You can enable or disable routes for use by the MCP server in `routes.js`.  Here's the kind of thing you can do with MCP (from Claude, Slack, or anywhere) in any Sails app; not just games, but finance software, consumer apps, admin tools, real estate transaction tech, and more:
